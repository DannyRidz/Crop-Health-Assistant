## Options considered

| Decision | Recommendation and reason | Runner up and tradeoff |
|---|---|---|
| Application shape | One app, fast to build and operate with two people | Separate API service can isolate scaling but adds deployment and coordination |
| Persistence | Tab memory, matches one assessment and avoids saved photos | Durable case store allows resume but adds privacy, deletion and consent work |
| Questions | Reviewed bank with bounded AI selection, easy to translate and test | Free text follow ups are flexible but increase wording and meaning risks |
| Model | Current stable Flash with verified image and structured capabilities, evaluate before claims | Another current Gemini model may suit cost or latency, but changing requires documented comparison and repeat evaluation |
| Language | Canonical checked result plus cached text variants | Asking the model to screen again in each language can change evidence and cost |
| Report | Direct selected language PDF, reliable sharing artifact | Browser print view is smaller to build but phone save workflows differ |
| Hosting | Cloud Run, preferred and supports one server application | Google Firebase is permitted but offers no clear benefit for this server and stateless scope |
| Frontend | Organic field guide with photo relationships | An unstyled native form saves styling time but makes observations harder to relate to photos |
| Geography | One optional country or broad region context and explicit reviewed guidance matches, no precise location | Automatic location inference is convenient but unreliable and could wrongly imply suitability; worldwide treatment guidance needs reviews beyond this MVP |

These choices favour a complete visible thread over breadth. The costs are refresh loss, limited demo capacity and content review dependencies that software cannot bypass.

Public access does not require a worldwide guidance collection. A PNG only reviewed collection can coexist with supported observations, regional limitation notices and local officer referrals for other farmers. Additional region specific guidance belongs on the roadmap, with evidence and review before use. A lightweight server guidance reselection reuses the checked observations and avoids extra Gemini cost when the farmer corrects their region.
